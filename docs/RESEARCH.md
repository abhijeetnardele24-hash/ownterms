## 2. Research Findings

### PayPal Developer Ecosystem & APIMatic
- PayPal partnered with APIMatic to release official context plugins for AI coding environments.
- Verified APIMatic CLI version: `1.29+`. Installed PayPal plugin containing TypeScript models and guides for Orders v2, Payments, Invoicing, and Subscriptions.
- Orders v2 is the gold standard for e-commerce and checkout integrations. We leverage the two-step order creation + capture with server authorization.

### Agentic Commerce & IP Licensing
- According to recent industry shifts, autonomous AI agents are becoming primary economic actors purchasing APIs, cloud compute, and digital media.
- Intellectual Property licensing requires deterministic boundaries: rights granting must never be entrusted to non-deterministic generative models.
- By separating extraction (AI) from authorization and pricing (code), OwnTerms provides an enterprise-safe architectural pattern.
